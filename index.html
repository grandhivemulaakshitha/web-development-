CampusIQ — Adaptive Academic Context Engine

AI / Agentic System

An AI academic copilot built to solve a problem most study apps ignore: a student's academic life is scattered across timetables, syllabi, deadlines, notes, and quiz scores, and no single system reasons across all of them. Ask a normal chatbot "what should I study tonight?" and it gives generic advice based only on the question text — it has no idea an exam is in 8 days or that you scored 45% on your last quiz on that exact topic.

CampusIQ is designed around adaptive context selection instead of a fixed retrieval pipeline. Rather than always running the same "search notes → answer" flow that standard Retrieval-Augmented Generation (RAG) systems use, it first classifies what kind of question is being asked, then dynamically decides which sources actually matter — course material via RAG, structured data like exams and deadlines, or the student's own performance history — and combines them before generating a response.

For a query like "what should I study tonight?", the system pulls tomorrow's timetable, upcoming exams, pending assignments, syllabus progress, and quiz performance, then reasons over all of it to give one specific, personalized recommendation — for example, telling the student to focus on a particular topic tonight because of a low quiz score and an approaching exam, rather than a generic study tip.

The underlying research question: does adaptive context selection produce more relevant, personalized answers than a traditional RAG pipeline? The project is designed to be evaluated on context relevance, response relevance, personalization, tool-selection accuracy, and hallucination rate against a standard RAG baseline.

Solar-Driven Drip Irrigation Controller

IoT / Embedded

An automated irrigation system that runs entirely on solar power, built to help small farms water crops efficiently without manual effort or a grid connection. A soil-moisture sensor continuously checks how dry the ground is and a microcontroller uses that reading to switch the water pump on only when the soil actually needs it — instead of watering on a fixed schedule.

The solar panel and battery setup keep the system running independently in the field, which matters for areas with unreliable or no electricity. By watering on demand rather than on a timer, the system reduces water wastage and helps prevent both overwatering and underwatering, which can directly improve crop health and yield.

Key parts: moisture sensor for real-time soil readings, a microcontroller (e.g. Arduino) to process sensor data and control the pump relay, solar panel + battery for power, and a drip mechanism for targeted, low-waste watering.

Student Attendance Tracker

Web App

A web application built to replace manual paper attendance registers with a faster, more reliable digital system. Faculty can mark attendance for a class in a few clicks, and the system stores it against each student's record instead of a physical sheet that can get lost or miscounted.

The app keeps a running history of attendance per student, so percentages and patterns (like frequent absences) are easy to check at a glance instead of manually tallying registers at the end of a term. It's built with standard web development tools — a front end for marking and viewing attendance, and a backend with a database to store and retrieve records reliably.

The goal was to save faculty time on routine record-keeping and give students and staff a clear, accurate view of attendance at any point in the semester.
